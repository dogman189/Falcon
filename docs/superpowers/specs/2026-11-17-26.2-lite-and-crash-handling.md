# 26.2 Lite Bundle and Crash Handling

## Problem
- The bundled 26.2 client was a large custom "Chromium Client" single-file build that packaged Standard, Sodium, and Sodium + Iris variants behind a premenu.
- On iPhone, `com.apple.WebKit.WebContent` was repeatedly killed by Jetsam for out-of-memory (observed peak ~154k pages / ~2.47 GB at 16 KB pages), causing crash/restart loops.

## Bundle changes
- Replaced `Falcon/26.2-wasm.html` with a lite direct-HTML build derived from the extracted 26.2 payload.
- Removed unused variant/template/capture payloads: `gx-variant-performance-wasm`, `gx-variant-shaders-wasm`, `gx-variant-template`, and `gx-bundle-capture`.
- Result: bundle reduced from ~100 MB to ~77 MB on disk (~80.6 MB payload) while keeping the premenu bypass hook.
- The original 100 MB bundle is kept as an out-of-repo backup at `/private/var/folders/n1/wqr4z1ld7xg0pw8ds3l50zk40000gn/T/opencode/eagler-extract/26.2-wasm-original.html`.

## Launch behavior
- `BundledClient` now supports optional query/fragment parameters and a selector note.
- `26.2-wasm` launches with `?nomesh&chunkunload=capped#nopre=1` to bypass the premenu and reduce runtime memory pressure.
- Simulator debug logging confirmed `WKWebView.loadFileURL` preserved the query and fragment for the bundled file URL.

## Crash handling
- `EaglerWebView` reports WebContent termination and navigation load failures through a coordinator callback instead of letting iOS repeatedly relaunch the page.
- `ContentView` shows a failure screen with **Try again** and **Back to clients** actions and resets failure state when switching clients.
- A debug launch argument `--client=<name|resource>` can auto-open a bundled client for testing.

## Verification
- Clean simulator build succeeded and the lite 26.2 build reached the main menu on an iPhone 17 / iOS 27.2 simulator.
- Physical-device stability on iPhone 14 Pro (iOS 27.2, UDID `00008120-000945080244C01E`) still needs manual verification; if 26.2 still OOMs, consider `?singlethread&chunkunload=capped` or further payload reduction and keep recommending `1.8.8-wasm`/`Eaglet`.
